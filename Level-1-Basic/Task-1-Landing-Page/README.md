---

## 📌 Project Overview
NovaFlow is a sleek, modern SaaS landing page designed for a high-velocity developer platform. It is built strictly following modern web standards, semantic HTML, fluid typography, mobile-first responsive architecture, and accessible interactive components.

---

## ✨ Features & Objectives Met

- [x] **Semantic HTML5:** Structured using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` for accessibility and SEO.
- [x] **CSS Flexbox & CSS Grid:** Grid used for responsive multi-column feature cards and pricing tiers; Flexbox for navigation bar, tags, and aligned components.
- [x] **Mobile-First Responsive Design:** Clean media queries tailored for Mobile (< 640px), Tablet (640px – 991px), and Desktop (992px+).
- [x] **Dark / Light Theme Toggle:** Instant theme switcher utilizing CSS custom properties (`--bg-primary`, `--text-primary`) and `localStorage` to preserve user preferences.
- [x] **Animated Metrics Counter:** Uses `IntersectionObserver` to trigger an animated number counter when scrolled into view.
- [x] **Interactive Pricing Switcher:** Toggles between Monthly and Annual billing (with 20% discount calculation).
- [x] **Accessible FAQ Accordion:** Clean collapsible cards with ARIA attributes (`aria-expanded`) and smooth CSS transitions.
- [x] **Mobile Drawer Navigation:** Accessible hamburger button toggling an animated slide-down navigation menu.
